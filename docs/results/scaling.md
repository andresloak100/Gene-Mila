## Is the ordering real?

- scripted control (no LLM) @ 2492e11, 4 workers (6 runs): identical results every time, sealed gain 0.0341, visible gain 0.0150. The scripted recipe is deterministic on this dataset, so this control is a fixed-recipe reference, not a noise reference.
- scripted control (no LLM) @ 2492e11, 4 workers ended after 2.1 min on average (its hypotheses ran out) against 20.3 min for the agent arms, so it is not an equal-time arm: it shows what the fixed template features give, not what a no-LLM search of the same length gives.
- scripted control (no LLM) @ 537344f, 4 workers (1 run, the same scripted hypotheses every time; what varies is timing, scheduling order and the exploit follow-ups that order produces): sealed gain 0.0331, visible gain 0.0068. Its spread bounds the timing noise of a short deterministic run, not that of the agent arms, whose own repeats are the yardstick below.
- scripted control (no LLM) @ 537344f, 4 workers ended after 2.7 min on average (its hypotheses ran out) against 20.3 min for the agent arms, so it is not an equal-time arm: it shows what the fixed template features give, not what a no-LLM search of the same length gives.
