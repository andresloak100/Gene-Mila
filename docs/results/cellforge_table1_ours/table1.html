Predicting unseen genetic perturbations, CellForge's Table 1 with our rows

The same six metrics as CellForge, on Adamson 2016 and Norman 2019. Our rows were all scored on one fixed split, so they compare with each other. CellForge's rows are copied from its paper.

Why CellForge's rows are not comparable

CellForge uses its own split and preprocessing. Its published numbers could not be reproduced under any metric definition we tried. Its PCC and MSE are also on a different scale, so read its rows as context only.

The agents

LLM research agents write features for a plain ridge model on CPU. A DeepSeek v4-pro planner and four DeepSeek flash workers run for 20 minutes per seed. Each run's selected model is scored once on the sealed set. Run T0 repeats run G0 on current code. G1 adds three gene-annotation tables.

Baselines

Unperturbed predicts the control mean. The lab's starting model is the first experiment of every run. Linear follows Ahlmann-Eltze et al. 2025, and GEARS follows Roohani et al. 2023 with 20 epochs on CPU. GEARS falls back to the mean training change for perturbations outside its gene graph.

Data and receipts

Adamson's baseline rows use a corrected export with 1,770 more control cells than the agents' bundle. Norman's export matches the bundle exactly. Every number traces to a run directory in docs/results/cellforge_table1_ours/table.md on PR #112.
