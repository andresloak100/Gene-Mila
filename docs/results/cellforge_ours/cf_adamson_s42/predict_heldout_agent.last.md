`predict_heldout.py` is written and smoke-tested. It imports `result.py` and trains its exact model on all training groups (control + all observed perturbations) for the full 30 epochs on CPU with no validation split; for each held-out key it hashes the perturbation string to a one-hot bucket, embeds it with the perturbation MLP, encodes the control-mean log-normalized expression through the 4-layer transformer, conditions per-gene tokens via cross-attention, and predicts a per-gene delta so the output is `baseline + delta`. The full-gene output (38 × 2055, in the file’s gene order and log1p scale) uses the model’s delta for the 512 selected highly-variable genes and the control mean (zero predicted change) for the rest. The smoke test on a 2,000-cell subsample with one epoch produced `perts` as a string array and `means` as float32 `(38, 2055)` with no NaN/Inf, and `smoke_predictions.npz` was deleted. Expected full runtime is roughly 10–15 minutes on a 4-core CPU, dominated by the 30 single-batch training epochs.
